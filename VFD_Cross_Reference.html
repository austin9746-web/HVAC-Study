Pre-Swap Checklist

☐ Record ALL parameter settings from old VFD before removing
☐ Photo the control wiring at old VFD terminals
☐ Check incoming voltage (208/230/460/575) matches new VFD rating
☐ Verify HP/kW rating matches or exceeds motor nameplate
☐ Check carrier frequency (switching freq) — may need adjustment for cable length
☐ Note the BMS signal type (0-10V, 4-20mA, BACnet, Modbus, etc.)
☐ Record PID setpoint and tuning values if applicable
☐ Check min/max frequency limits and accel/decel ramp times
☐ Verify fault relay (NO/NC) wiring matches BAS alarm input
☐ Test run in HAND mode before switching to AUTO
