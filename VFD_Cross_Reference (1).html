Cable Length & Reflected Wave

Long motor cables cause voltage reflections that stress motor insulation. These are the NEMA MG-1 Part 31 limits.

Cable length > limit: Use inverter-duty motors (NEMA MG-1 Part 31 rated for 1600V peak spikes). For runs over 300 ft, use a sine wave output filter.

VFD Duty Types

Variable Torque (VT)
Fans, pumps, blowers. Torque \u221d speed\u00b2. Can use smallest VFD. 110% overload for 60 sec. Most HVAC applications.
Constant Torque (CT)
Compressors, conveyors, positive displacement. Full torque at all speeds. Need next size up. 150% overload for 60 sec.
Heavy Duty (HD)
Hoists, grinders, crushers. Starts against high load. Two sizes up from VT. 200%+ overload. Rarely used in HVAC.

Pre-Swap Checklist

☐ Record ALL parameter settings from old VFD before removing
☐ Photo the control wiring at old VFD terminals
☐ Check incoming voltage (208/230/460/575) matches new VFD rating
☐ Verify HP/kW rating matches or exceeds motor nameplate
☐ Check carrier frequency (switching freq) \u2014 may need adjustment for cable length
☐ Note the BMS signal type (0-10V, 4-20mA, BACnet, Modbus, etc.)
☐ Record PID setpoint and tuning values if applicable
☐ Check min/max frequency limits and accel/decel ramp times
☐ Verify fault relay (NO/NC) wiring matches BAS alarm input
☐ Check for any digital I/O programming (run permissives, etc.)
☐ Test run in HAND mode before switching to AUTO
☐ Verify rotation direction matches before coupling load
☐ Document final parameters for future service
